# Home Pal App  
*Powered by Purple Cove Labs*

This project was built as part of the *“Learn to Code with AI”* course on Scrimba.  
The goal was to customize a smart home interface and turn it into a downloadable mobile-friendly app.

---

## 🛠️ Customizations & Features

I customized the base project to reflect my own style, preferences, and functionality. Below are the key changes I implemented:

---

### 🎨 Theme & Branding

- Kept the original purple theme, as it aligns well with *Purple Cove Labs* branding.
- Updated the app name from "HomeHarmony" to "Home Pal".
- Changed the main header to reflect the new title.
- Added a small "Powered By" header with the Purple Cove Labs logo.

---

### 💡 Lighting

- When the lighting toggle is switched ON, the container background changes to a bright energy-saver blue, and the toggle slider turns gold.
- This creates a more realistic “light turned ON” effect.

---

### 🌡️ Temperature Control

- Set the default temperature to *21°C*, which I personally consider a comfortable neutral.
- Introduced dynamic background gradients:
  - Temperature *increases* shift the background toward red.
  - Temperature *decreases* shift it toward blue.
- Added animated emoji states:
  - ❄️ At *16°C* or below: shows an *ice emoji* and a *freezing thermometer animation*.
  - ☀️ At *30°C* or above: shows a *sun emoji* and a *hot thermometer animation*.
  - At *21°C*, everything returns to the neutral look.

---

### 🎵 Music Integration

- Replaced static song names with real music playback using the YouTube API.
- The app now plays actual YouTube videos from my favorite playlists.
- Each click of the "Next" button loads a random track from the predefined playlist.

---

### 🎚️ Music Visual Feedback

- When the Play button is clicked, the music section background shifts to a green gradient.
- When Stop is clicked, it reverts to the original color.

---

### 🧾 Footer

- Added a footer showing my name (Gamal Jastram) and Purple Cove Labs as the creator of this build; something I include in all my projects.
